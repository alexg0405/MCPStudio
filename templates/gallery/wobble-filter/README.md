# Wobble Filter

An effect for a mixer track. A low-pass filter lets low sounds through and cuts the highs; here a slow wave moves its
cutoff up and down, which gives wobbles, wah-wah and breathing pads.

- **Cutoff**: the middle of the sweep.
- **Resonance**: how much the filter rings.
- **Rate**: how fast it moves. **Depth**: how far, in octaves each way.

The sound code is a few lines of Faust in `filter.dsp`: open it with Edit code and change it, and the knobs follow.
