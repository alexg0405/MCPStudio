# Tape Stop

An effect for a mixer track. While **Stop** is off the sound passes straight through. Turn it on and the last few seconds
play back ever slower until the sound stops, pitch and tempo sinking together. Turn it off and the tape spins back up
and the live sound returns.

- **Slow down**: how long the stop takes.
- **Spin up**: how long the tape takes to get back to speed.

Tip: link Stop to automation, with the stop switched on in the last beat of a bar.
