# Bit Crusher

An effect for a mixer track that makes sound grittier in two ways.

- **Bits**: rounds every sample to fewer levels. 16 is clean, 8 is an old console, 3 is mostly noise.
- **Sample rate**: looks at the sound less often, which darkens it and adds a metallic, aliased edge.
- **Mix**: blend between the clean and the crushed sound.
